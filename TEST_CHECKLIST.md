# v0.13.1 — Disting NT quick test checklist

**New in v0.13.1**
1. Pages read **Edit, Pattern, Output, Gate, Clock, Routing, Chain**. Plugin still opens on Edit segment. A v0.13.0 preset loads unchanged.
2. **Gate page:** Gate out, Gate mode, Gate threshold, Gate out mode. Changing Gate out here also changes it on Routing.
3. **Edit order:** Shape's controls right under Shape, then Duration, Repeats, Timing … Squish, Morph to, Gate trigger, Duplicate, Delete, Reset, Add/remove.
4. **Morph to controls:** on a Sine segment, Morph to Square shows Pulse width; Morph to Steps shows Steps/Contour/Curve; Morph to Off hides them again.
5. **Random Morph to:** Ramp segment, Morph to Random, Random steps 4, Morph 100%: values change every pass (Free). Set Refresh = Loop: values hold; Regenerate segment changes them on the next loop. Save/reload keeps them.
6. **Random → Smooth random:** Shape Random, Morph to Smooth random: Morph sweeps from hard steps to smooth glides.

**Still open from v0.11–v0.13:** Gate trigger, Mult/div, Step loop, Init pattern, chainer, morph CPU, Duplicate/Delete, 32 segments and saving, Pattern loop range, quantizer, worst-case CPU.
